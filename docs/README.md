# Finca San Pedro Glamping

Web estática pública con fotografías reales recuperadas de la web anterior y del portafolio de la finca.

Publicación: GitHub Pages, rama main, carpeta /docs. No requiere WordPress, servidor PHP, paquetes ni servicios de pago. El pre-check-in se completa en KoBo; sus respuestas y la sincronización por correo permanecen fuera de este repositorio.

Logo original en assets/images/logo-finca-san-pedro.png. Azul petróleo y verde del logo con fondos crema. Las tarifas visibles provienen del tarifario 2026; el menú oficial está incluido como PDF.

Para actualizar fotos, reemplazar el archivo correspondiente en assets/images conservando su nombre o actualizar index.html. Usar originales de 1600–2400 px de lado largo; se publican en WebP optimizado.
